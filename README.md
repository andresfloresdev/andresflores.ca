# andresflores.ca

Andrés Flores's personal site. Astro on the tela-astro boilerplate, French and English.

```sh
npm install
npm run build                                    # checks, then builds to dist/
SITE_URL=https://andresflores.ca npm run build   # production build (indexable)
npx astro preview                                # serve the build
```

Start with `AGENTS.md`, then `docs/brief/site-brief.md`. The tela-astro
engineering notes are `docs/01` to `docs/11`.
